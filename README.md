# Colony Creation

A Minecraft modpack built around **Create**, **MineColonies**, **Exosphere** and **Create: Aeronautics**. Build factories, found a colony and explore the world by airship, all with a progression where metals no longer come straight out of a furnace.

| | |
|---|---|
| **Minecraft** | 1.21.1 |
| **Mod loader** | NeoForge |
| **Platform** | CurseForge |
| **Status** | Work in progress |

> This repository contains only the modpack's **configuration** (scripts, configs, documentation). The mods themselves (`.jar` files) are intentionally not included. The full list is in [`docs/mods.txt`](docs/mods.txt).

---

## Main Mods

- **Create** plus many addons (Aeronautics, Metallurgy, Enchantment Industry, Connected, Deco and more)
- **MineColonies** with its questline and companion mods
- **Exosphere**
- **Create: Aeronautics** for airships and flight mechanics

---

## Repository Structure

```
kubejs/          Recipes, LootJS scripts, server and startup scripts
config/          Mod configs (including FTB Quests)
defaultconfigs/  Default configs for new worlds
docs/            Documentation (progression, mod list)
```

Everything else (worlds, logs, caches, maps, mods) is excluded via `.gitignore`.

---

## Installation

The pack is still in development. To try it out:

1. Install the mods listed in [`Modpack on CurseForge`]([docs/mods.txt](https://www.curseforge.com/minecraft/modpacks/p3a-per-aspera-ad-astra-sky-high-colony)).
2. And enjoy the modpack!
